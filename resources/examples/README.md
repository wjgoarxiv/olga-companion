# Bundled examples

Synthetic teaching cases only. Nothing here is customer data.

The gallery lists an example only after it compiles and the app validator accepts it, and only when every pressure and temperature stays inside the bundled air-water table (0.5–20 bar, 0–80 °C). Toolkit topologies outside that range are not listed: the table cannot carry them to a result.

`air-water-horizontal` is the tutorial demo. It compiles `resources/tutorial/demo_case.json`. `simple-pipeline` comes from the toolkit builder (`simple_pipeline`) with the fluid label set to `AIR_WATER`.
