OLGA Companion 튜토리얼

실제 앱 화면과 움직임을 옮겨 놓은 연습판입니다. 말풍선이 가리키는 곳을 직접 눌러 7단계를 따라가세요. 실제 OLGA나 AI에는 연결되지 않고, 화면의 값과 응답은 모두 합성 예시입니다.

모션

7단계

    앱이 지키는 약속

    연습판에서도 실제 앱과 같은 순서로 멈춥니다.

    1. 사례 저장, 파일 쓰기, 실행은 모두 승인 카드나 실행 화면에서 사람이 직접 눌러야 진행됩니다.
    2. 어시스턴트가 대신 승인할 수 없습니다.
    3. 실행은 격리 실행 폴더의 사본으로 돌고, 원본 사례는 바뀌지 않습니다.
    4. 배관표 마법사는 요청 문장을 입력창에 넣기만 하고 전송하지 않습니다.

    테마와 모션 선택은 이 브라우저에만 저장됩니다. 실제 앱에서는 상단 튜토리얼 버튼으로 같은 7단계 안내를 엽니다.
